# Student Database SQL Project

A simple database project using SQLite in Google Colab to simulate a student report system.

## Tech Used
- Python
- SQLite
- Google Colab
- Pandas

## Features
- Create student table
- Insert multiple entries
- Run SQL queries for:
  - All records
  - Top scorers (marks > 85)
  - Average marks by grade
